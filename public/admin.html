Optimasi Foto

Mengecilkan foto lama yang sudah terlanjur besar (foto kamera 2–6 MB) supaya web ringan di laptop/HP lemah. Foto baru yang di-upload sekarang otomatis dikecilkan, jadi ini cukup dijalankan sekali.

Yang dilakukan: setiap foto di atas 400 KB diunduh, dikecilkan (maks 2000px, WebP), di-upload sebagai file baru, lalu link-nya di database diganti. File asli tidak dihapus — tetap ada di Storage kalau suatu saat dibutuhkan.

Klik "Cek ukuran foto" dulu.
